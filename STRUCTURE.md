# Repository Structure Guide
# avillasisdev/avillasisdev

## 📁 Folder structure

```
avillasisdev/
├── README.md          ← Main profile README (what GitHub shows)
├── STRUCTURE.md       ← This file (setup reference)
└── assets/            ← Optional: banner image, profile assets
    └── banner.png     ← (add your own if you want a custom banner)
```

## 🎨 Design tokens used in README.md

| Token | Value | Usage |
|-------|-------|-------|
| Background | `#0D1117` | Badge backgrounds |
| Accent Blue | `#4A9EFF` | Icons, highlights, graphs |
| Text muted | `#8B949E` | Secondary text |
| Accent dark | `#3D7FBB` | "learning" badges |

## ✅ Customization checklist

- [ ] Replace `#` in LinkedIn badge with your real LinkedIn URL
- [ ] Replace `#` in Portfolio badge with your portfolio URL
- [ ] Add your custom `banner.png` inside `assets/` (optional)
- [ ] Update project repositories once they're published
- [ ] Update `learning.log` progress bars as you advance

## 📌 Badge convention

- `style=for-the-badge` → active skills / main tools
- `style=flat-square` with `label=learning` → technologies in progress
